# Vitrine Cultural

Modelo **gratuito e de código aberto** de site-portfólio para artesãos, músicos, bandas, grupos de teatro, artistas plásticos e demais agentes culturais divulgarem seu trabalho na internet, **sem pagar hospedagem e sem saber programar**.

Projeto de extensão universitária (Programa de Ação e Difusão Cultural) do curso de Bacharelado em Ciência da Computação.

## O que o site tem

- Página inicial com nome, tipo de arte, cidade e uma frase de apresentação
- **Galeria de trabalhos** com foto, descrição, preço e filtro por categoria
- Botão **"Tenho interesse"** que abre o WhatsApp com uma mensagem pronta
- Seção **Sobre** para contar a história do artista ou grupo
- **Agenda** de feiras, shows e exposições (eventos passados somem sozinhos)
- Contatos: WhatsApp, Instagram e e-mail
- Funciona em celular e computador, com modo claro e escuro automático

## Como usar (resumo)

1. Crie uma conta gratuita no [GitHub](https://github.com).
2. Neste repositório, clique em **Use this template → Create a new repository**.
3. No seu novo repositório, abra o arquivo **`dados.js`**, clique no lápis (✏️) e troque os dados de exemplo pelos seus.
4. Envie suas fotos para a pasta **`imagens`** (botão *Add file → Upload files*).
5. Vá em **Settings → Pages**, escolha a branch `main` e salve.
6. Em alguns minutos o site estará no ar em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO`.

O passo a passo completo, com explicações para quem nunca usou GitHub, está no **[Guia em PDF](guia/Guia_Vitrine_Cultural.pdf)**.

## Estrutura dos arquivos

| Arquivo | Para que serve | Precisa editar? |
|---|---|---|
| `dados.js` | Todos os textos, contatos, trabalhos e agenda | **Sim** |
| `imagens/` | Fotos dos trabalhos | **Sim** (troque pelas suas) |
| `index.html` | Estrutura da página | Não |
| `estilo.css` | Aparência (cores, fontes, layout) | Não |
| `script.js` | Monta a página a partir de `dados.js` | Não |

## Testar no computador

Basta abrir o arquivo `index.html` no navegador (duplo clique).

## Dados de exemplo

O "Ateliê Barro Vivo" usado como exemplo é **fictício**, assim como seus contatos. As ilustrações da pasta `imagens/` foram feitas para este projeto e podem ser usadas livremente.
